# 📊 Risk Operations Analytics

## 📌 Project Overview

This project demonstrates an end-to-end Risk Operations Analytics solution using SQL Server, Power BI, and Microsoft Excel.

The objective is to analyze operational performance, premium collection, claims, risk distribution, compliance status, and SLA performance through SQL queries and interactive Power BI dashboards.

---

## 🎯 Objectives

- Analyze operational case data
- Monitor premium and claim performance
- Identify high-risk cases
- Evaluate regional performance
- Track compliance and SLA metrics
- Build an interactive management dashboard
